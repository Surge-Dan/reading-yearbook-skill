# HTML阅读年鉴操作

## 任务与默认产物

一份单文件HTML，包含年度统计、已完成月份的时长趋势、已载入书籍的主分类分布、真实事件时间线、可筛选书架、划线／个人笔记及分享导出。缺失月份保留缺口。用户只要图片时，复用已有HTML或按本次材料构建，通过同一个ReadingShareArtwork渲染器预览与导出，不切换到旧share-workflow，也不扩大书目或交付范围。

默认先由助手蒸馏至少一本，再选择“加一本或生成报告”，最后网页阅读与导出。新建真实报告必须有至少一份共享验证器通过的 real 包，缺少时在采集或写文件前提示“先蒸馏至少一本”，保留已有报告且不创建空报告；示例仅能以 source_mode=sample 单独构建并只含 sample 包。已有HTML打开不触发新建门。

助手完成微信读书采集和网页交付；年份未指定默认本年并说明。鉴权失败不拿示例替代真实记录。蒸馏书目只在底部阅读，不能据此改变年度已读数、时长或书目版本。网页只读，无上传、开始指令、任务接口或模型连接；静态导出不调用模型。HTML本身无图片比例，分享出口支持3:4、1:1与4:5。

## 自动交付入口

助手运行，用户无需填写JSON：

```powershell
python -X utf8 scripts/generate_reading_html.py --year 2026 --distillation output/books/已完成任务/deep/distillation.json --output output/reading-2026/index.html
```

Key从环境变量读取，不进入参数或交付。私人缓存按授权、年份和日期隔离；只复用当前用户的有效材料。新采集超过100本时先返回`needs_scope_confirmation`并说明范围；用户明确同意后才加`--allow-large-yearbook`，已有完整材料不受此限制。年度排行已覆盖官方读过总数时跳过额外候选扫描；否则结合书架与分页笔记本发现候选，再以实际进度和本年日期核实。完整笔记逐书采集，零记录有效；覆盖不足如实说明。可用`--annual-snapshot`、`--materials`和`--covers`复用已核验材料，不为视觉修改重采。

封面缺失或损坏时自动使用书名／作者占位，照常生成指定HTML并打开年度报告，不自动转为草稿或阻塞。先在既有授权／预算内按书籍身份补采对应版本书封，不用同名不同版本凑数，不扩大到全文采集或第三方搜索，不无限重试。缺图和材料局部失败记为partial，网页仍可浏览和导出；不能称材料齐全。`--allow-draft`仅保留为主动另存内部草稿的选项。同一授权与年份的上次笔记保存在私人状态缓存中；刷新失败保留已有内容，成功核查为零才清空。有效接口也不保证返回逐日数据或所有书目；未知不补零。脚本退出码0为完整，3为可用但材料不全，2为阻塞；缺封面不属于阻塞。交付前由助手使用已有浏览器测试离线文件及导出，不要求用户安装运行时。

## 使用已有材料构建

```powershell
python -X utf8 scripts/build_reading_html.py --input reading-data.json --distillation output/books/第一本/deep/distillation.json --distillation output/books/第二本/deep/distillation.json --output output/reading/index.html
```

接受原始`shelf/stats/book_details`、规范化`summary/books`或已有`share-job.json`。已有分享任务包通常仅有精选书，用`--annual-snapshot`补充年内书目，不能直接加入整个书架。年度快照包含`annual.readLongest`、`shelf.books`与可选`non_ranked_progress`；后者只纳入实际开始阅读且末次阅读在本年的书。快照需通过显式year或annual.readTimes日期核验年份，跨年快照拒绝合并。

`--distillation` 可重复，或已有输入包含 `distillations:[bundle]`。build_html、deliver 和自动生成入口均调用共享验证器，不以数量代替内容校验；坏包、篡改包、失败任务或真实报告中的 sample 都拒绝。包公开 analysis/digest 直接内嵌到安全转义的 JSON，不包含原始整书、私有路径、令牌或过程输出。`input_mode:upload|title` 与 `source_mode:real|sample` 独立，书名资料保持未核验全文的范围。

底部默认选第一本，多书切换只改变精华内容；复制、Markdown、独立HTML、PNG与ZIP来自当前所选同一结果并保留来源边界。可选阅读视角与金句按[读懂与表达](book-reading-writing.md)，有内容才出现；旧结果缺字段继续读取，不伪造新内容。

`--covers covers.json`映射书籍ID到本地PNG/JPEG/WebP路径，路径相对covers.json。构建时检查图片完整解码，缺失、路径失效或图片损坏时清除无效图片并使用已有书名占位样式，保留书目、统计、笔记和其他真实封面。工作台照常载入缺封面的旧HTML，仅书目数据损坏时拒绝载入。只有明确要求全真实封面时才使用`--require-all-covers`，此模式缺图会在写文件前停止并保留上一版。网页和离线构建本身不请求远程封面，材料采集阶段取得的有效真实封面会内嵌，不生成伪装成真实版本的封面。

### 补齐书籍材料

已有组图任务只保留精选片段，不能将其当成完整年鉴的笔记输入。补全年内书目后，逐本核实封面、当前进度、完整划线及个人想法；只请求已确认的书，不重采整个书架。使用：

```powershell
python -X utf8 scripts/collect_html_materials.py --input share-job.json --annual-snapshot annual-snapshot.json --output private/html-materials
python -X utf8 scripts/build_reading_html.py --input share-job.json --distillation output/books/已完成任务/deep/distillation.json --annual-snapshot annual-snapshot.json --book-materials private/html-materials/materials.json --covers private/html-materials/covers.json --output output/reading/index.html
```

采集脚本读取环境变量中的Key，两个并发任务、复用有效缓存、按游标拉取全部个人想法；单书最多20页，超过时停止扩批，版本升级或鉴权失败停止新请求。可用`--legacy-cache`复用旧的`bookId-highlights.json`／`bookId-thoughts.json`。缓存及封面留在私人目录，错误状态不写成空笔记。构建器只合并当前年鉴已有书籍，不让额外书目混入。

详情默认载入该书全部历史记录，并注明范围；年度时间线只取本年事件。确认接口完整返回0条时写“已核查，无记录”，请求失败或只取了片段时写“未完整载入”。年度统计优先读取官方`readStat/readDays/totalReadTime`及月度分桶；当前进度100%的筛选和官方年度读完汇总分别保留，不能为了对齐数字篡改任何一方。刷新统计同时更新采集日期。划线区支持按书籍筛选，导出保留材料范围。

缺少读完、进度、日期或逐书时长时显示未知，不从年度总量分摊。每本书保留一个来源主分类，层级分类第一层用于分布，原始分类保留在数据中。书目覆盖和材料覆盖分别检查；有15本身份不意味着15本都有划线或个人笔记。

资源、代码及书封均内嵌；字体优先本机Noto中文字族，其他设备回退系统中文字体。当前生成器未内嵌字体文件；若需跨设备字形一致，取得可再分发字体并做子集后再内嵌，不暗示已完成。

沿用原字体家族、花体Reading、宋体标题、蜡笔插画和图表。本次局部修订去掉 body／paper 彩色渐变，使用单一纸色与中性外背景，按钮／输入约8px、卡片约12px，取消任务／上下文的引用式左边线；原始引文仍保留自身表达。固定英文装饰已在图片中，中文统计书名可选择。艺术素材与数据分离，只内嵌一次；`--art-assets art.json` 的 hero／reading／rhythm 可显式替换，不按书名自动换风格。

## 无材料与失败处理

有划线时展示原文摘录；只有个人笔记时主区展示想法并标注“我的笔记”。两者都没有时保留完整书架与真实统计，只显示一次温和说明；单书分享用书封、作者、分类和已知进度，不把“未载入”等系统说明印在分享图上。

每本书详情只展开有内容的材料区，缺少的材料给出简短状态。已完整核查的零记录与请求失败必须不同；失败保留已有内容，说明可让助手重新同步。没有年内书目时隐藏无用筛选和翻页，明确年份及零记录／未取得的区别。时间线只用真实日期，不因无笔记虚构开始阅读或读完事件。

网页、打印、Markdown、JSON不包含生成书评、全文来源占位或全文搜索状态；也不自动开展全文检索。书籍简介来自接口，与用户笔记分开。

## 纸面与控件

参考图的蓝色外缘、暖色细边线、大范围低对比色雾、纸纤维与铅笔线共同建立质感。色雾跨章节分布，不给每个组件加渐变。花体、中文宋体和紧凑正文保持层级；简笔画放在留白与章节连接处，不覆盖文字。真实数据与艺术素材分别维护；当前纸面是示例方向，不强制所有用户使用相同风格。

搜索用SVG并按几何中心对齐；书架展开按钮居中。书籍和比例选择采用统一纸色浮层，支持方向键、Home/End、Escape、Tab、点击外部关闭、长书名换行和滚动。手机浮层不越界；减少动态与打印不受装饰影响。

## 图表

月度图适配lieflat-charts Basics B2/F2真实骨架：日历地板、细线、逐点、峰值读数；月份取代日序列，原始秒数决定位置，缺失断线，真实零值落在基线，尚未到的月份不入图。选择月份可用键盘，另有准确时长表。

分类使用有纸边和轻微错位的彩色书脊块，小书目一块一本；最大分类超过10本时采用全图统一分组单位，尾块按数量比例显示并说明单位，避免节点数量无界增长。显示准确本数与四舍五入占比；点击或键盘选择后筛选书架。逐书投入使用真实小书封和实心横条，同一比例尺由零到最大时长，未知不补零，真实零保留，完整准确秒数另有表格。横条是时长比较，不是阅读进度或喜爱排行。手机上标题与横条分行。两类图保留原有滚入、独立重播与错峰动画框架；连续重播取消旧动画。缩放只重绘最终帧，不能把图停在透明初始状态。减少动态效果与打印立即显示完整图，Canvas直接绘制最终数据，不截动画中间帧；分享图重排书脊块和横条，分类颜色与网页一致。

分布用已载入去重书目计数，进度未知不归“在读”。时间线只纳入有真实日期的划线、笔记、明确初读与读完事件；笔记日期不转换成开始日期。没有逐日数据不制作热力图。

lieflat图表代码保留PolyForm Noncommercial 1.0.0完整许可，内嵌到HTML来源区，商业用途需满足原许可条件。新配色遵循用户认可方向，不偷偷固化到所有年鉴。

## 分享与导出

分享出口从当前年鉴全部已载入书目建立单书卡，不按精选标记、书架搜索或分页裁减。封面、阅读统计、阅读分布、阅读时间线及全部书籍默认勾选，也允许用户取消。四张概览单独展示；书籍使用纸色多选浮层，支持搜索书名／作者、勾选、独立预览、全选、清空和完成。搜索只筛选可见行，不改变选择；全选和清空只作用于书籍。Escape关闭并恢复触发器焦点，浮层适配移动端并保持在视口内。

书籍数量、已选书籍数、已选页数、总页数均从实际数据和选择状态计算，禁止复用示例数量。预览不改变勾选；整组ZIP只包含当前选中页面，成员数必须与已选页数一致。导出期间锁定调整，失败保留选择并解锁重试。零书目禁用书籍选择器，仍可预览与导出四张概览；没有分类、月度时长或日期事件时展示对应真实空态，不补零或捏造记录。

先预览独立分享画布，再调整页面选择。可从详情或摘录选择具体划线加入分享，支持撤销。Canvas输出本地PNG，整组为PNG的ZIP；没有安装Playwright也能在用户浏览器中导出。分享页长文字以省略号明确截短，完整内容保留在HTML与Markdown。

分享图由独立`reading-share-art.js`渲染，预览和下载使用同一绘制入口。当前认可示例是阅读杂志特刊：强对比字重、错落书封、纸面色雾、主图与侧栏；这是当前示例方向，不替所有用户固定风格。封面取实际书目和汇总，统计组合月度细线与已知逐书时长，分类合并后的其他项须保留准确合计，时间线按真实月份组织。分类刻度多时提升统一单位并注明，月度缺失仍断线，逐书时长不代表推荐排序。

书卡以实际材料量决定结构：短摘录与书封分栏，长摘录优先正文，个人笔记与引文分开标注；可补充互补摘录，不凭书名编观点。接口简介明确标“内容简介”。无划线／笔记／简介时放大书封，组合真实阅读状态和原创图案，不填充无用系统文字；未完整取得的记录不印成0条。书名优先在主副标题处分行，重要读数不截短，三种比例分别计算可用空间。默认使用已认可的本机Noto／系统字体回退策略；保留字体资源与OFL许可，不自动内嵌不同字族以免改变字重和断行。跨设备字体一致性方案须先经样张认可。

PDF打开浏览器打印对话框，包含当前筛选书架及对应详情、划线与笔记，不显示网页控件。Markdown与JSON包含年鉴已载入内容与来源，JSON不重复内嵌封面；都不带密钥、鉴权响应或整本正文。

字体／书封／画布未就绪或生成失败时停止该次导出，保留选择并展示原因，不用旧文件报成功。页面制作后实际测试file协议及离线浏览，点击每个导出按钮核验文件。

## 验证与成本

只读本参考及当前数据，不同时加载所有设计和gallery。既有统计不重采，视觉修改不重读记录。只采年鉴候选书，默认不检索全文或OCR；很大书架／超过分页上限时说明范围与覆盖，不能无限扩批。

测试1440／768／390px，长中文、空记录、未知状态、输入法、筛选清除、键盘与减少动态效果。核验图表位置和数据、PNG尺寸、ZIP成员CRC、打印分页、Markdown来源、JSON结构，检查网络请求和控制台。对抗式审查另做一轮：恶意文本、重复记录、缺失月份、坏书封、连续导出、空选择和数据口径冲突。

动态图表另运行`tests/reading_html_art.cjs`：核验真实动画对象、滚入完成、连续重播清理、缩放后细线可见、减少动态效果、打印最终帧和分数刻度。先生成一份含已知／未知逐书时长的测试年鉴，不能用纯静态检查替代浏览器验证。

分享画布另运行`tests/reading_share_art.cjs`：实际渲染五种页型与三种比例，核对文字边界及碰撞、月度几何、分类合计、长书名、无笔记、空书目和较长书单，并比较预览与下载PNG。浏览器文件离线测试不能替代审美认可，先展示四张代表样张及375px预览再确认后续扩展。


## 安装、刷新与数据闭环

助手先运行`python -X utf8 scripts/skill_release.py`核对发布清单与必需资源。缺依赖时用当前Python运行`python -m pip install --target .vendor -r requirements.txt`；由助手处理，用户只提供授权与需求。支持Python3.9及以上；HTML浏览／PNG／ZIP导出不需要Playwright。

默认`--refresh reuse`复用当天校验通过的私人缓存；跨日期复用同账号、同年份的封面及带获取时间的原始材料，旧阅读记录仍重新请求，临时错误才回退旧材料并标记stale；`--refresh missing`重试缺失或结构失效材料；用户明确重新同步时用`--refresh all`。成功返回空列表可清空旧笔记，失败保留旧内容并标明未完整取得。更新周期按北京时间，临时文件校验通过后原子替换正式文件。

原始缓存保持接口结构；伴随的`.meta.json`记录缓存版本、接口名与北京时间获取时间。旧缓存通过结构校验后兼容读取；损坏或不兼容版本需要重新采集。强制刷新遇到暂时错误时，校验通过的旧材料标为`stale`；鉴权／升级／参数错误仍停止，不以缓存掩盖。候选预算包含笔记本分页和逐书扩查的新请求，不含最初的书架与年度汇总两项；接口内部重试最多一次。已核验书目的材料采集为每本3项＋想法分页，默认两并发、每本想法最多20页；超过100本先确认范围。没有token节省率承诺。

本机同一Python环境可用`skill_release.py --install 目标目录 --with-local-dependencies`同步已安装的`.vendor`；它不是跨操作系统的二进制依赖包。新设备按自身Python安装`requirements.txt`。资源清单不会删除安装目录里用户自行保存的文件。

候选发现超过100本或新请求超过`--discovery-budget`（默认100）时先返回`needs_scope_confirmation`及年度汇总草稿；确认后用`--allow-large-yearbook`继续。历史书目允许最近阅读在其他年份，实际年内完成／笔记证据仍须核实。书架与排行无法追溯的记录继续标未覆盖，不能承诺接口未提供的信息。

HTML数据为`reading-html/1.2`；可读取1.1／1.2导出的JSON，保留`summary.read/finished/seconds/monthly`、`finish_date/start_date`、`note_coverage`及`features`。历史笔记`scope: all_time`重新导入时不按目标年删除。`null`表示未取得，0只用于真实返回的零。旧档案与独立组图分别适配，不共用缺时长补零的语义。

`features`按真实年度字段生成：`daily`日期到秒数、`hourly`0—23点秒数数组、`category_time`官方返回分类时长、`read_seconds/listen_seconds`、`day_average`及`comparison`。这些字段保留在数据JSON中，当前默认网页不增加新的统计模块。新增图表需先确认布局；不新增逐日请求，分类时长与书架分类计数仍为不同口径。

页面沿用已认可的详情和句子区：详情保留完整划线／想法，打印保留全部材料；有划线时句子区展示划线，否则展示个人笔记。数据JSON保留个人想法中的`quote`和`range`；有声内容笔记接口未提供时保留unsupported状态。

想法分页在暂时错误、重复游标或20页预算处中断时，保留已经取得的部分，与此前材料按来源ID去重合并，标记`partial`；不能把这一批标成完整，也不能丢弃前19页的内容。鉴权、升级等终止错误仍停止整个采集。

分享出口恢复已认可版本：四张概览＋全部载入书籍，默认全部勾选，支持搜索、多选、预览和撤销；导出失败保留选择，单张PNG／整组ZIP／PDF／Markdown／JSON沿用原交互。当前不启用新增的取消、分卷、部分导出或私密排除控件；含私密材料的分享仍须由用户确认范围，助手先说明涉及的书目。
