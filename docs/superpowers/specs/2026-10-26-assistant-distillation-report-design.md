# 年年阅：助手蒸馏与报告解耦

日期：2026-10-26。用户已确认交互分工、至少一本结果的报告前置条件，以及活泼但有依据的读者表达；授权继续实现。

## 产品边界

助手接收书名或有权处理的 EPUB/PDF/TXT/MD，完成获准分析后保存可复用结果。网页是阅读与导出界面，不承担上传、选择执行器、启动模型、预算确认或复制交接指令。年度报告保持首页，书籍精华在底部。

报告生成前至少有一份有效的真实结果包；书名资料模式也可计入，但身份确认、上传成功、失败任务、示例不能冒充有效蒸馏。已有报告继续可读可导出，不因新规则锁定或删除。新增结果不意味着该书属于用户年度已读书目，不能修改阅读统计或强行按书名关联版本。

## 方案取舍

采用共享蒸馏核心 + 助手入口 + 静态报告。拒绝继续网页提交/聊天接力，也不新增独立模型 API 或多宿主自动连接工程。已有本机服务可以作为助手私有的阶段传输通道，但读者页面不连接其任务接口，助手无需用户去网页操作。

保留原解析、定位、来源门、当前会话身份和取消/超时/成本边界；不重跑私人长书、不承诺任意宿主可用。UI 原有字体家族、插画、图表和排版主体保留，只移除彩色渐变、统一控件圆角和任务装饰。

## 蒸馏方法

1. 所有输入分块都进入内容地图，保留人物、论证线、作者主张、关键主题与未解决问题。
2. 上传正文改为每批一次联合提取框架、原则、案例、反例和术语；保留逐类扫描结果（允许确无内容），不再五次无条件重读全文。
3. 跨章节去重不丢独立条件；仍逐项核验候选和全局任务覆盖。原始分块、证据和出处可回查；不减少证据或用摘要代替尚未处理的正文。
4. 内容地图、方法、案例、解释和书评使用同一证据身份。多次模型判断不称独立盲测或已证明增益。
5. 缓存按实际输入、规则和版本失效，只复用通过检查的阶段；失败、取消不能留下正式成功包。

## 面向读者的表达

不把内部类别原样变成严肃表格。基础概览、人物/逻辑、核心观点、方法、书评、参考资料仍可使用；新增可选阅读视角，例如“全书最在意的事”“书中透露出的底色”“最值得争论的一处”。选择与书有关的视角，不强凑栏目或数量，不编造作者价值观、私下动机或用户亲历。

“值得保留的金句”只收录有精确来源的原文；助手自写的漂亮句子不冒充作者引文。书名模式的二手转述不放入原文金句。解释、短引文和来源在网页、Markdown、独立HTML及分享图保持一致，审计细节集中参考区。

## 数据接口

新增 `scripts/distillation_result.py`：`make_bundle(analysis, document, digest='')` 在真实证据上验证后生成结果包；`validate_bundle(bundle)` 验证公开包结构/绑定；`load_bundle(path)` 读取验证。包是 `schema_version:1, kind:'reading-distillation', analysis, digest, source_hash, input_mode, checks, bundle_hash`。无全文、令牌、账户凭据或私有过程输出。源码哈希、原文/公开资料模式与书籍身份不能混用；文件内容变动使包哈希校验失败。哈希是完整性校验，不是独立语义质量证明。

`analysis` 兼容现有字段，可选新增 `reading_lenses:[{id,kind,title,text,sources}]` 和 `memorable_passages:[{text,why_it_matters,sources}]`。kind 是 values/tone/tension/connections；所有视角需真实证据，金句 text 必须逐字匹配指定来源，书名模式仅原书公开试读可作原文。

已完成管线原子发布 `distillation.json`。报告数据使用 `distillations:[bundle]`，多个结果只展示不合并成一本书。新真实报告构建与自动生成入口必须验证至少一包；公开示例明确 source_mode=sample，仅能附示例包。旧文件打开不触发新建门。

## 助手入口与引导

助手可直接从本地路径/书名创建任务，处理阶段、同名选择、范围确认、重试/取消均可在助手命令中完成；不再要求用户操作网页。可复用现有安全的私有回环通道，不让用户执行命令或暴露令牌。成功后自然询问“再加一本，还是生成报告？”。高成本仍先确认，不自动全书重试。

## 验收边界

测试无结果、无效/失败/篡改结果、书名模式、正文模式、多书展示、引用脚本注入、旧报告打开、缺封面占位、分享和离线下载。先红后绿，集成时确认报告生成无模型调用。用短篇受控正文做完整流程的测试替身；它只证明工程链路，不证明实际模型质量。

另外提供有界质量比较协议：同材料、同预算条件下比较关键内容覆盖、来源准确、方法可执行性、人物/论证理解、中文可读性、实际调用与消耗。记录上游版本和真实结果，未做比较前不称“超过仓颉/book-to-skill”。真实长书和额外模型评测另行确认。
